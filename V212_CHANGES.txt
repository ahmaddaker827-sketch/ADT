ADT Stock V212 — التحكم داخل التطبيق الرئيسي

1) في لوحة المطور: المستخدمون، صيانة التطبيق، إشعار قبل الصيانة.
2) زر المستخدمين يعرض الاسم والهاتف والمتجر والدور والحالة، ويتيح تعيين كلمة مرور جديدة للأعضاء دون كشف القديمة.
3) أرسل إشعار الصيانة أولاً، ثم اختر بدء الصيانة عند الموعد؛ إنهاء الصيانة يعيد التطبيق للعمل.
4) الجرد المدفوع متاح من لوحة المطور > إدارة المتاجر > الباقات والميزات.
5) زر تصفح سري أصبح عرض فقط، مع منع التعديل خلال عرض متجر آخر.

خطوات التشغيل:
- نفّذ ملف V212_DEVELOPER_INSIDE_APP_AFTER_V206.sql مرة واحدة في Supabase SQL Editor بعد كود V206 المجمع الحالي.
- لا تحتاج إلى تشغيل ADT_CONTROL_MULTI_APP.sql أو ADT_CONTROL_OWNER_ONLY_V3.sql أو ADT_CONTROL_STOCK_ONLY_V4.sql.
- انسخ ملفات المشروع كاملة إلى مستودع GitHub وابنِ APK عبر إعداد البناء المعتاد.
- صيانة التطبيق والتنبيه تحتاج اتصال المستخدم بالإنترنت؛ يُراجع التطبيق الحالة عند فتح الرئيسية ثم دورياً كل 3 دقائق.
- ملف ZIP هو مشروع المصدر، وليس APK جاهزاً للتثبيت.
